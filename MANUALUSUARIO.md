# Manual de Usuario - SendMessage

Esta aplicación te permite redactar un mensaje y enviarlo a otra pantalla para visualización.

### Pasos para usar la aplicación:

1. **Redactar el mensaje:** Escribe el texto que deseas enviar en la casilla blanca central de la pantalla principal.
2. **Enviar el mensaje:** Pulsa sobre el botón "Enviar mensaje" situado en la parte inferior.
3. **Ver el mensaje:** En la siguiente pantalla verás la confirmación visual de que el mensaje fue enviado y el texto exacto que has redactado.
